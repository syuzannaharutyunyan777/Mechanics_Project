
# Billiard Simulation Project

This project aims to **simulate different billiard models** and investigate their physical properties using a simulation approach.  
The models covered include:  
- 🎱 Circular billiard  
- 🎱 Vertical circular billiard  
- 🎱 Horizontal stadium billiard  

The main objective is to study how particles move inside these systems, focusing on their **paths, reflections, and momentum changes**.

## Project Goals
- Simulate different billiard table geometries  
- Observe particle trajectories under repeated reflections  
- Analyze how momentum changes during collisions  
- Understand the connection between mechanics and real-life examples  

## Insights & Observations
- Balls move **irregularly**, with each particle taking a different trajectory depending on the model.  
- Despite differences in geometry, randomness in particle paths emerges across all simulations.  
- The project illustrates how mechanics, normally seen as abstract, is **directly connected to real-world phenomena** like billiards.
